## 附三 · `[镜头]` 替换菜单（8 项）

```
正面直视          正面半身，面部朝向镜头，双眼看向镜头，目光平视          ← 默认，最标准的正脸
正面微侧 5–10°    正面半身，面部朝向镜头，头部偏 5 到 10 度            ← 仍是正脸，比全正更自然
正面微抬下颌      正面半身，面部朝向镜头，下颌微抬，目光直视镜头        ← 冷冽、有压迫感的角色
正面微低          正面半身，面部朝向镜头，头部微低，眼皮略垂            ← 温婉、羞怯、忧郁的角色
四分之三侧        面部转约 45 度，目光看向镜头                        ← 五官仍完整可见，立体感更好
侧脸回眸          面部转约 90 度回望镜头，露出侧脸轮廓                  ← 氛围最强，但看不清全脸
过肩视角          从人物肩后拍向前方，只见侧脸与后脑                    ← 影视常用，不适合当角色设定
俯拍 / 仰拍       镜头从上方 15 度俯拍，或从下方 15 度仰拍              ← 改变气场，慎用
```

**前四项才是正脸，后四项是分镜角度。** 做角色设定图、定妆图、以及一切要拿去做一致性锚点的图，**必须用前四项**；后四项只用于正片里需要氛围的镜头，用它当锚点会让后续所有图都认不出正脸。

**出图仍是侧脸的补救顺序：** ① 把 `[镜头]` 那一行**提到提示词最前面**（位置越靠前权重越高）② 在 `[气质]` 里把"目光有压迫感 / 疏离感"这类词删掉或换成"目光平静直视镜头"③ 负面词里加"侧脸、回眸、背对镜头、只露半边脸"。

## 附四 · `[姿态]` 替换菜单（8 项）

```
上身端正 · 手不入画     上身端正，双臂自然垂放于身侧，双手不入画          ← 最干净，脸部最突出
双手交叠身前            上身端正，双手自然交叠放于身前，不触碰面部
一手搭另一手腕          上身端正，一手轻搭于另一只手腕上，位置在腰线以上，不触碰面部
双手轻握身前            上身放松，双手轻握置于身前，手指自然舒展，不触碰面部
双臂抱胸                上身笔直，双臂交叉抱于胸前，位置在胸线以下，双手不触碰面部        ← 气场强，但会挡服装
双手收于袖中            上身端正，双手收在宽袖之内，不见手                  ← 古装最稳，彻底免掉手部崩坏
双手交叠腹前            上身端正，双手交叠置于腹前，不触碰面部                        ← 中老年适用
手扶器物                上身端正，一只手轻扶桌面或栏杆（需在场景里写明器物）
```

**前三种最通用。** 做角色设定图与定妆图建议用第 1 或第 2 种，**手不入画或手放身侧，就不会有手部崩坏的风险**。

**手部控制的三道保险**：① `[姿态]` 写明双手去向 ② `[镜头]` 里可加"裁切于胸口以上"（胸像构图手根本不入镜）③ 负面词加"托腮、扶脸、摸头发、手托下巴、手挡脸、多指、六指、手指畸形"。
