# 使用规范与铁律

> 来源：角色脸型库（220 型）使用说明。生成/复用提示词前必读。

## 九项结构

每条角色由九项写死，从 `[性别]` 那一行开始整段复制，不改写、不补词：

```
[性别]   先锁性别
[妆容]   女性用（男性为 [面部]）
[骨相]   脸型、颧骨、下颌角、下巴
[五官]   眼型、眉形、鼻、唇形
[发型]   按年龄与气质配
[识别]   痣、疤、不对称（身份证）
[气质]   性格底色
[镜头]   正面半身 + 面部朝向镜头 + 目光方向
[姿态]   上身姿势 + 双手去向
```

## 六条铁律

1. **`[性别]` 那一行不能删。** 骨相描述（窄长菱形脸、颧骨外扩、薄唇）单独看无性别指向，去掉这一行模型默认往男性走。
2. **`[妆容]` / `[面部]` 那一行不能删。** 女性唇色一旦写成"淡/灰/裸"就变男人脸；库里唇色全部带具体色相（赤茶、暗玫瑰、豆沙、浅玫），是防性别漂移。
3. **`[镜头]` 那一行不能删，也不能只写"半身像"。** 不写朝向模型会画成回眸侧脸；条目默认值已写死"面部朝向镜头"。
4. **`[姿态]` 那一行不能删，尤其不能漏"双手"去向。** 不规定手放哪，模型会画成托腮/扶脸/撩头发；条目已写死"不触碰面部 / 双手不入画"。
5. **`[识别]` 那一行，一个字都别动。** 这是这张脸的身份证，是观众几十集后仍能认出角色的唯一依据。
6. **`[画风]` 和 `[光]` 不写在条目里，从替换菜单按需取。** 把风格层抽出，同一张脸才能走 16 种画风、8 种光型。

## 一剧一人原则

- 220 个识别锚点全部不重复，可放心大批量使用。
- **别把同一张脸跨项目复用**：平台在查跨剧撞脸，一剧一人才是安全做法。
- 同一部剧、同一季、番外与支线保留原人脸是合规的；换新剧就要换新脸。

## 出图仍是侧脸的补救顺序

1. 把 `[镜头]` 那一行**提到提示词最前面**（位置越靠前权重越高）。
2. 在 `[气质]` 里把"目光有压迫感 / 疏离感"这类词删掉或换成"目光平静直视镜头"。
3. 负面词里加"侧脸、回眸、背对镜头、只露半边脸"。

## 大跨度画风提示

- 写实 → 三渲二、赛璐璐：可直接上参考图。
- 写实 → 水墨、Q 版、剪纸：要先出风格再拽脸。
- **画风可以换，锚点不能丢**：变完之后先看小痣、疤、不对称位置是否保留，那是观众认人的第一依据。

## 手部控制的三道保险

1. `[姿态]` 写明双手去向。
2. `[镜头]` 里可加"裁切于胸口以上"（胸像构图手根本不入镜）。
3. 负面词加"托腮、扶脸、摸头发、手托下巴、手挡脸、多指、六指、手指畸形"。
