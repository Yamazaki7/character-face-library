# character-face-library · 角色脸型库（220 型）提示词生成器

一个 WorkBuddy Skill，用于从「千篇不一律 · 角色脸型库（220 型）」中按需检索角色，整段输出九项角色设定提示词，解决竖屏短剧 / AI 短剧工业化生产中的**跨集撞脸、角色认不出**问题。

## 能力概览

- **女性 120 型 + 男性 100 型**，共 220 个识别锚点全部不重复（精确到毫米与左右）。
- 按「性别 → 年龄段 → 气质 → 脸型」快速检索，整段输出九项提示词。
- 叠加 16 项画风、8 项光型、8 项镜头、8 项姿态四个替换菜单，产出可直接投喂 AI 生图 / 文生视频的角色一致性锚点。

## 九项提示词结构

每条角色九项写死，整段复制即用：

```
[性别]  [妆容]/[面部]  [骨相]  [五官]  [发型]  [识别]  [气质]  [镜头]  [姿态]
```

## 六条铁律（生成前自检）

1. `[性别]` 不能删（防女脸变男）
2. `[妆容]` / `[面部]` 不能删，唇色必须带色相
3. `[镜头]` 不能只写"半身像"，必须"面部朝向镜头"
4. `[姿态]` 必须写明双手去向
5. `[识别]` 一个字都别动（角色身份证）
6. `[画风]` 和 `[光]` 从菜单按需叠加，不写进条目

## 使用提醒

- 同一部剧内可复用原人脸；**换新剧必须换新脸**（平台在查跨剧撞脸）。
- 做角色设定图 / 定妆图 / 一致性锚点，`[镜头]` 必须用前四项正脸。

## 安装

将本目录复制到 `~/.workbuddy/skills/character-face-library/`（用户级）或项目 `.workbuddy/skills/`（项目级），WorkBuddy 会自动加载该 Skill。
